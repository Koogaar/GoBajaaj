What's New in SHIRI v4.0.0 — Biggest Release Yet!

🎯 Complete End-to-End Delivery Workflow:
• Customer orders → Merchant approves → Courier delivers → Handover PIN confirms.
• Real-time order status: Pending → Accepted → Preparing → Ready → In Transit → Delivered.
• Live GPS tracking with ETA badge and route visualization.

🏢 Business Dashboard — Fully Interactive:
• Orders tab: View, filter, and manage all orders with full detail modal.
• Products tab: Add, edit, delete products with stock toggle and search.
• Finance tab: View earnings, today's breakdown, and withdraw via mobile money.
• Kitchen Alarm alert for new incoming orders.

🗺️ SHIRI Address — Somalia's Digital Address System:
• Every home gets a unique digital code (e.g. SHR-MG-48291).
• QR code, GPS coordinates, district + street bundled in one address card.
• 15-second voice landmark recording for delivery guidance.

👨‍💼 Admin Web Dashboard (Revamped):
• Full order management with detail modal (PIN, customer info, bill breakdown).
• Merchant products management (add/edit/delete products per merchant).
• Revenue chart and live order table with status advancement.

💳 Mobile Money Payments:
• Hormuud EVC Plus, Somtel eDahab, Telesom ZAAD, Sahal — all supported.
• Auto-generated USSD payment code for seamless checkout.

🔧 Performance and Bug Fixes:
• Significantly faster app loading and screen transitions.
• Fixed all non-clickable tabs in Business Dashboard.
• Improved Somali language localization throughout.
• Cleaner red brand theme across all screens.
